# Knight's Quest: The Videogame

## Short description
Knight's Quest is an engaging platform game where players take on the role of a courageous medieval knight. The knight embarks on a thrilling adventure through diverse environments, including lush forests, treacherous caves, and other fantastical landscapes, each filled with challenges and enemies.

* Genre: Platformer


## Gameplay
Players will navigate through various levels, utilizing classic platforming mechanics such as running, jumping, and dodging obstacles. The knight will encounter various foes, solve environmental puzzles, and collect power-ups to enhance abilities. As the player progresses, they will face increasingly difficult challenges leading up to the ultimate showdown against the kingdom's evil monster.


## Objective
The main objective is to successfully traverse through each level, defeating enemies and overcoming obstacles, ultimately leading to the confrontation with the evil monster that threatens the kingdom.


## How to play the game

| **Action** | **Input** |
| --- | --- |
| Move left and right | A -> Left  /  D -> Right |
| Jump | Spacebar |
| Jump diagonally left and right | Jump + left or right (A and D) |

### DEBUG SHORTCUTS
| **Debug Action** | **Input** |
| --- | --- |
| Show/Hide help menu | H |
| Debug Camera | F8 |
| Visualize Colliders Logic | F9 |
| God Mode | F10 |
| Enable / Disable fps cap to 30 | F11 |
| Save stats | F5 |
| Load stats | F6 |



## List of features implemented

### General Gameplay
- Basic player mechanics (move, jump)

- Collisions: Platforms, walls and spikes collisions detection (and reaction of the player in each case)
  
- Camera following: the camera is always following the player (X and Y wise)
  
- Minimum debug functionality (F8, F9, F10… keys): God mode, help menu, debug camera and show colliders
  
- Minimum loop gameplay: Basic gameplay with die condition and player respawn

- Basic animations: Run, Jump, Fall, Die (all of them left and right)
